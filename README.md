# CEM Research Lab website
 [![DOI](https://zenodo.org/badge/1383922225.svg)](https://doi.org/10.5281/zenodo.22923742)
Source for [cemresearchlab.com](https://cemresearchlab.com), built with Jekyll on GitHub Pages.

## How to post to the blog (no HTML needed)

1. Open the `_posts` folder on GitHub.
2. Click **Add file → Create new file**.
3. Name the file with today's date, then a short title with dashes, ending in `.md`:
   `2026-10-05-new-findings.md`
4. Copy everything from `POST-TEMPLATE.md` into the file, change the title, and write your post.
5. Click **Commit changes**. The post appears on the site in 1–2 minutes.

To **edit** a post or page, open the file and click the pencil icon. To **delete** a post, open it, click the **···** menu, and choose **Delete file**.
